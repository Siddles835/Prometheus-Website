Learning path

Join our classes

A clear path from first lines of Python to confident work with real data structures.

Level 01

Python Fundamentals

Start your coding journey with variables, data types, and basic I/O.

  • Variables
  • Data Types
  • Input/Output
  • Strings
  • Numbers
Level 02

Control Flow & Functions

Learn to make decisions in code and write reusable functions.

  • If/Else
  • Loops
  • Functions
  • Scope
  • Error Handling
Level 03

Data Structures

Master lists, dictionaries, sets, and how to work with complex data.

  • Lists
  • Dictionaries

  • Comprehensions
